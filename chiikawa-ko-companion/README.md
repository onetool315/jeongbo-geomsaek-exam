# 치이카와 모브 한글화 + 자바판 기능 이식 (폰마크/베드락 동반 애드온)

베드락 애드온 **Chikawa Mob (Popular Biology)** 위에 얹어 쓰는 **별도 팩 2개**입니다.

> 원본 애드온 소스에는 "무단 수정·재배포 금지(All rights reserved)" 표기가 있어, 이 저장소에는 **원본 파일이 하나도 들어 있지 않습니다.**
> 원본 `.mcaddon`은 직접 받아서 따로 설치하세요. 이 팩들은 원본 엔티티 ID(`popularbiology:*`)만 참조합니다.

## 설치 (폰마크)
1. 원본 `ChikawaMob_BehRes_v1_2.mcaddon` 설치
2. `dist/ChiikawaKR_Companion.mcaddon` 설치 (BP + RP 동시에 들어갑니다)
3. 월드 설정 → 리소스 팩/비헤이비어 팩에서 **둘 다 활성화**
   - 리소스 팩 순서는 **한글 팩이 원본보다 위**여야 번역이 우선 적용됩니다.
   - 설정에서 언어를 한국어로.
   - 월드 설정에서 **베타 API는 필요 없지만**, 스크립트 지원(Minecraft 1.21.60 이상)이 필요합니다.

## 한글화
`RP/texts/ko_KR.lang` — 원본 애드온의 이름/메시지 키 전부 + 새 아이템·블록. 자바판 `ko_kr.json`의 번역을 재사용했습니다.

## 이식한 기능
| 자바판 기능 | 베드락 구현 |
|---|---|
| 호루라기 사탕 | 우클릭: 32칸 내 내 펫 전체에게 명령, 웅크리고 우클릭: 따라오기 ↔ 자유 행동 전환 |
| 펫 종 | 다른 차원까지 내 펫 전부 소환, 30초 쿨다운 |
| 작업 안내서 | 사용법 9개 항목을 폼으로 표시 |
| 노동 게시판 | 매일 작업표 (레벨+2개). 잡초 제거 / 근접 사냥 / 원거리 사냥. 에메랄드로 레벨 업. 작업표를 펫에게 맡기면 진행, 보상은 펫 가방으로 |
| 잡초 제거 | 작업표를 받은 펫이 10칸 안의 가장 가까운 풀로 걸어가 제거하고 집계 |
| 사냥 | 작업표를 받은 펫이 16칸 안의 몬스터에게 다가가 공격(근접 4, 원거리 3 피해), 처치 수 집계. 펫이 쓰러지면 작업표 실패 |
| 시험용 책상 + 면허 | 다이아 1개로 등록 → 다음 날 아침 결과. 3급→2급→1급, 작업 경험·학습 가이드·불합격 보정 확률. 면허 등급이 오르면 작업 보상 증가 |
| 잡초 제거 학습 가이드 | 펫에게 우클릭하면 읽힘, 시험 때 소모 |
| 상점 | 플레이어 구매/판매 폼. 설치된 상점 24칸 안에서 펫이 용돈(에메랄드)으로 쇼핑 |
| 선물 | 펫이 가끔 선물을 사서 주인이 가까이 오면 직접 전달 |
| 용돈 | 에메랄드를 들고 펫 우클릭 → 펫 가방에 들어감 |
| 간단한 요리 | 펫에게 먹이면 5분간 속도·성급함 증가 |
| 펫 대사 | 자바판 `voice.*` 대사를 말풍선 대신 채팅으로 표시 |

레시피는 `BP/recipes/` 참고 (펫 종 = 종 + 끈, 사탕 = 설탕×2 + 막대기, 게시판/상점 = 판자 + 에메랄드 등).

## 이식하지 못한 것 (베드락 제약 / 원본 코드 없음)
- 배낭·파우치로 펫 가방 슬롯 확장, 케이크로 인형 부활, 오르골(MP3 불러오기), 거리 공연, 사냥 이외의 상세 AI(밭 작업, 배달 등), 펫이 직접 걸어가서 책상에 앉는 연출, 야생 펫 호루라기 구경, 펫 상태 전용 화면.
- 소유자 정보를 베드락 API가 주지 않아, 길들일 때 가장 가까운 플레이어를 주인으로 기록합니다. 이미 길들인 펫은 한 번 우클릭하면 그 사람이 주인으로 기록됩니다.
- 원본의 "앉기" 상태는 보조 엔티티 연출에 묶여 있어 사탕은 **따라오기/자유 행동**만 전환합니다.

## 내 폰용 통합 빌드 (개인 사용)
원본 `.mcaddon`을 직접 가지고 있을 때, 한글 번역을 원본 팩에 합친 개인용 파일을 만듭니다. 결과는 `personal/`(git 제외)에 생기며 공유하면 안 됩니다.
```
python3 tools/build_personal.py /경로/ChikawaMob_BehRes_v1_2.mcaddon
```
스크립트 모듈은 `@minecraft/server` 2.0.0 / `server-ui` 2.0.0 (26.x 대응, 최소 엔진 1.21.100)입니다.

## 테스트 (가짜 API로 1단계 로직 검증)
```
tests/run.sh
```

## 개발
```
python3 tools/generate.py        # lang, 텍스처, 대사/매뉴얼 데이터 생성
python3 tools/generate_defs.py   # manifest, 아이템, 블록, 레시피 생성
python3 tools/build.py           # dist/*.mcaddon, *.mcpack 패키징
```
> 게임에서 직접 테스트하지 못했습니다. 스크립트 문법과 JSON만 검증했으므로, 안 되는 부분이 있으면 콘텐츠 로그(설정 → 크리에이터 → 콘텐츠 로그 GUI)의 오류를 알려주세요.
